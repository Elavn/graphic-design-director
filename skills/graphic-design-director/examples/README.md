# Examples and calibration

This skill deliberately does **not** ship client brand images, private project files, historical mockups or other projects’ approved assets. Universal examples live in `references/deep/decision-examples.md` and cross-project cases in `evals/deep-regression-cases.md`.

For a real task, keep the brief, images and feedback in that task's own project folder. Do not load a previous client's palette, symbol, vehicle or moodboard as a default for new work.
