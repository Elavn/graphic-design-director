# Fidelity and diversity regression matrix

## Fidelity must outrank style novelty in adaptations

- Adapt a landscape reference grid for a new brand whose primary color differs from the reference. Preserve normalized panel boundaries, required copy, and aspect ratio; apply new brand palette in the intended color roles. **Fail** for an unrequested dramatic change of template, a wrong artboard size or a prior brand's dominant color.
- Adapt a source containing an intentional app-demo panel. Preserve that panel's position and content category unless user requests its replacement. Unrelated browser chrome is not part of the designed artifact.
- Recreate text-free, flat 4:5 transport artwork. **Fail** for any text, invented CTA, 3D materials, photorealistic rendering, filled top 35%, or swapped vehicle scale relationship.

## Diversity must not deform fixed references

- For an open creative brief with no image reference, develop at least two structurally different visual routes before committing; reject identical cream-grids and floating objects across unrelated work if not justified.
- For an exact replication brief, do **not** invent an alternative cinematic/maximalist/editorial approach to demonstrate diversity.

## Evaluation discipline

Inspect the resulting pixels and mark each hard constraint PASS/FAIL, with dimensions read from file metadata. Rate visual/art-direction quality only after the hard checks pass. Admit any observed deviation in layout or logo integrity; never assign unsupported numerical similarity.
