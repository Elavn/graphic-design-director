# Visual reference regression cases — derived from the user's three examples

Each test is a **manual design-and-critique case**. Create a new graphic, then test at actual size and at 25%; evaluate without comparing pixel similarity to the uploaded reference artworks.

## VR-01 — Expressive typographic landing graphic
**Brief:** First fold for a local independent creative-writing community, with headline “Stories find their people.” Intended for web desktop and mobile. Audience 18–35. No navigation data given.
**Pass:** original dynamic typographic silhouette, meaningful serif/sans role contrast, one pastel or signal-color focus strip, grid discipline, small annotated editorial details only if accurate; mobile hierarchy preserved.
**Fail:** reproduces user's reference title/layout/stickers; illegible overlapping words; invents fake navigation; treats grid paper as mandatory.

## VR-02 — One-metaphor awareness visual
**Brief:** Poster about the importance of protecting public libraries. No statistics supplied. Need a strong image and clear CTA “Support your local library.”
**Pass:** emotionally legible **original** physical metaphor, coherent light, strong use of negative space, short copy and accessible contrast; does not invent data or use the reference rope arrangement.
**Fail:** fake percentage; visually pretty but meaningless surreal object; metaphor too small to recognize on a mobile feed.

## VR-03 — Playful ad that integrates product and metaphor
**Brief:** Social campaign for a creativity workshop. Promise: “Build ideas together.” No partner software licenses are supplied.
**Pass:** unexpected but relevant tactile physical metaphor; satisfying controlled collision of photo and graphic cutouts; clear headline; small optional utility text; no copied spoon/hand/icons structure.
**Fail:** replicates the spoon concept, uses real logos without approval, decoration unrelated to creativity, unreadable tiny text.

## VR-04 — Resist template monoculture
**Brief:** Create three concepts for a legal consultancy, an experimental music event and a neighborhood cultural exhibition.
**Pass:** substantially distinct concepts and visual signatures; not all giant serif or pastel collage; cultural details checked.
**Fail:** all projects use the same editorial grid, pastel chips, surreal physical object and tiny footer.

## VR-05 — Exact text preservation
**Brief:** Image-generating model asked for flyer with supplied event title, venue, date, price and phone number.
**Pass:** every glyph accurate in output; if model can't render exact text, place using vector/text overlay or clearly mark as not final.
**Fail:** generated approximate phone or impossible-to-read footer and claimed delivery complete.

## VR-06 — Feedback loop actually changes rules
**Brief:** User critiques a poster as “The concept is strong but CTA cannot be read on phones.”
**Pass:** give precise observation, fix CTA, propose narrow rule `Check CTA at realistic mobile scale`, append a regression case and versioned change after user-approved revision. No claim of weight training or automatic background process.
**Fail:** generic “I'll learn from this,” huge rewrite changing unrelated style guidance, or silently publishing updates.
