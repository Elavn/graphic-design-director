# Deep skill — cross-project behavioral regression cases

These are **manual evaluation cases**, not a claim that any model has executed them. For each future run, save the brief, actual output, pass/fail evidence, and critique. The cases test *behavior*, not specific house aesthetics.

| ID | Mode | Prompt shorthand | Pass condition | Hard failure |
|---|---|---|---|---|
| D01 | CREATE | Art-house film poster, no references | Distinct central idea, poster not UI | navigation tags, fake audience stats |
| D02 | CREATE | Plain 2D transport comparison, strict negatives | Flat fill; size relationship; designated whitespace | CGI, photo, text in text-free art |
| D03 | ADAPT | Swap new approved logo/palette into a screenshot-derived composition | Layout skeleton preserved, identity replaced | source brand remains, unrequested UI |
| D04 | REPLICATE | Match reference visual geometry | Consistent anchor positions, crops, type proportions | gratuitous new concept, wrong ratio |
| D05 | INSPIRE | Use source's editorial rhythm only | Original visual idea and composition | cloned panel positions or branding |
| D06 | SYSTEM | Brand logo selected, moodboard requested | Logo locked, limited applications | new invented symbol or unrelated vehicle |
| D07 | CRITIQUE | “Too bulky” | Diagnose density and visual hierarchy | empty praise, automatic template replacement |
| D08 | CREATE | Luxury cosmetics packaging concept | Material/typography/physical constraints considered | fake legal details and unrequested gold glow |
| D09 | CREATE | Local market public launch | Audience-specific, credible images and copy | fabricated figures, fictitious testimonials |
| D10 | CREATE | Experimental album cover | Distinct concept without relying on same modernist grid | default cards, icons, app UI |
| D11 | ADAPT | Preserve a product's physical silhouette | Subject type and category retained | van replacing cargo tricycle; invented hardware |
| D12 | CREATE | Identical exact brief and locked brand in new aspect | Correct reflow, original hierarchy retained | stretched logo, clipped headline |
| D13 | CREATE | Infographic with no data supplied | Requests source or uses labeled placeholders | fabricated percentages, misleading chart |
| D14 | CREATE | Culturally specific multilingual poster | Correct scripts/diacritics, respectful imagery | stereotyped motifs, mangled type |
| D15 | SYSTEM | Wordmark-only black/white stage | Three truly distinct typographic structures | gradient mockups, vehicle collage |
| D16 | CREATE | Reference provides only quality bar | New concept and colors derived from brief | forcing reference's brand palette into unrelated job |
| D17 | ADAPT | Brand alert red prohibited as background | Approved primary background dominates | saturated alert red becomes main field |
| D18 | CREATE | Requested 1080×1350 | Actual file exactly that size | inferred wrong dimensions or assumed export success |

## Required review evidence

Record `constraint pass/fail`, `concept diagnosis`, `typographic evidence`, `composition evidence`, `brand/reference drift`, `production limitation`, and `repair recommendation`. Do not assign percentage fidelity from subjective feeling.
