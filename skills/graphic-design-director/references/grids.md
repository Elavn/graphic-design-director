# Grids, layout, hierarchy and intentional disruption

**Conceptual influences:** Josef Müller-Brockmann, Timothy Samara, Ellen Lupton and Jennifer Cole Phillips.

## Foundation
1. Define hierarchy in words **before** placing boxes. Every element must have an importance rank and a relationship to neighboring elements.
2. Choose the appropriate organizing principle: 1-column editorial, 2–6-column modular, asymmetric split, baseline grid or centered axis.
3. Establish consistent margins, internal gaps and alignments; vary them by a discernible rhythm rather than accidental pixels.
4. Group related facts through proximity, alignment, enclosure or typography. Separate unrelated information clearly.
5. Use negative space to create pace and emphasis—not merely as empty decoration.
6. Establish one focal point and one dominant entry path. Secondary elements should not compete at the same intensity.
7. Break the grid **after** constructing it: a deliberate overlap, bleeding photograph or oversized headline is strongest when stable alignments remain elsewhere.

## Working scales (starting points, not laws)
- Choose a spacing unit appropriate to scale: e.g., 4/8px rhythm for screens, or a modular spacing increment for print.
- Reuse a small set of spacing steps (e.g., 8, 16, 24, 40, 64) and revise optically.
- Reserve extra space near high-attention display elements instead of applying the same gap everywhere.
- Use an asymmetric balance check: is weight distributed well by **visual mass**, not by equal geometry?

## Modern composition techniques
- **Editorial split:** typography occupies one column zone, imagery another; shared baselines keep it coherent.
- **Overscale crop:** headline runs large and crops *only when context still makes it legible*; supporting copy provides complete meaning.
- **Strong margin:** one consistent outer frame and a large open zone for emphasis.
- **Offset module:** one component steps outside the grid while the rest reinforces it.
- **Collage grid:** deliberately layered elements still align to a small number of invisible columns and edges.
- **Modular multi-format:** same underlying relationships survive 1:1, 4:5 and 9:16 by reflow, not by squashing.

## Stress tests
- Blur the design: is the hierarchy still obvious?
- Cover the main headline: do the remaining modules still read in a useful order?
- Remove background texture: does the composition still work?
- Crop to phone-size preview: are headline and CTA still legible?

## Reject and repair
- **Reject** six unrelated left edges. **Repair:** consolidate alignment anchors.
- **Reject** every object centered. **Repair:** test an asymmetric grid with a purposeful focal path.
- **Reject** dramatic asymmetry that loses the call to action. **Repair:** reinforce its contrast or location.
- **Reject** overpacked information. **Repair:** prioritize, separate into zones, or use a carousel/multi-page sequence.

## “What these books would reject” heuristic
A grid is neither a cage nor a decoration. Accidental disorder is not the same thing as intentional disruption.
