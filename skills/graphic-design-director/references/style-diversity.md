# Creative variety without default-aesthetic contamination

## Style is a consequence of the brief, not a signature of the model

There is no preferred default of serif typography, neo-Swiss grids, surreal props, orange/cream, blue gradients, UI stickers, collage hands or glassy 3D. These are **available techniques**, not elements that make something "modern." When a reference/brand/brief locks the style, preserve it even if it resembles prior work.

## For unconstrained CREATE briefs: three-route audition

Internally propose at least three distinctive routes; don't force the user to review all three unless asked. Each route must change at least three of these axes:

1. **Idea:** metaphor / product demonstration / type-driven identity / character story / documentary portrait / striking abstraction.
2. **Composition:** centered iconic / asymmetrical / diagonal narrative / field-of-type / panoramic / modular / dense immersive / isolated negative-space.
3. **Material:** flat vector / ink drawing / screen print / paper collage / photography / painted / clay / cinematic / cut vinyl / sculptural 3D.
4. **Typography:** absent / quiet functional / architectural sans / expressive serif / vernacular custom lettering / experimental distorted / mixed editorial.
5. **Color behavior:** monochrome / tight tonal / complementary / warm saturated / muted natural / chromatic loud / high-key / low-key.
6. **Energy:** minimal and still / playful / refined / loud / emotional / documentary / uncanny / dramatic.

Evaluate each route for **fit with purpose**, **distinctive concept**, **expressive execution**, **feasibility**, **legibility if text exists**, and **production compatibility**. Pick best, not flashiest and not simply least recently used. User preference outranks novelty.

### Important guardrail

Do not make stylistic diversity a randomizer. A quiet legal brochure may still need restraint; a reference-driven minimalist poster should remain minimalist. Creativity lives in **choosing well**, not adding effects.

## Style fingerprint, only when accessible

For each completed project, record locally when appropriate:

`medium | concept mechanism | grid/axis | type mode | color behavior | material/render mode | recurring motif | visual density | references | user-approved?`

When making another **unlocked** project, compare with recent approved work. If four or more fingerprint fields recur without a reason, examine a structurally different route. Do not claim persistent memory unless this record was actually stored and loaded.

## Expressive design is allowed

Avoid the counter-failure of bland correctness. The skill should deliver bold, maximalist, surreal, irregular, theatrical and highly expressive work when the concept supports it. Good design rules are about **purposeful control**, not compulsory minimalism. Broken grids, dramatic letterforms, asymmetry, unusual palettes, dense patterns and visual distortion can be deliberate design decisions.

## Diversity regression set

Given briefs for: (A) luxury watch launch, (B) child-focused science festival, (C) grassroots protest poster, (D) handmade ceramic studio, (E) conceptual public-health awareness ad, (F) underground electronic music show—evaluate whether concepts, hero media, layout and typography actually differ. Fail if the outputs share the same default masthead, little floating labels, detached hand, gradient or poster template regardless of brief. Contrasting designs must still maintain accurate information and medium fit.
