# Photography and reference-material fidelity

When adapting a reference, preserve the visual *medium* if it materially defines the source. A photographed human cannot silently become an illustrated character merely because the panel geometry remains similar.

## Source inventory

Record each focal region's medium: photography, illustration, CGI, vector type, collage, textured print, or mixed media. Note the actual human subject, cutout boundaries, shadows, grain, color temperature, aspect and focus. Lock medium where appropriate to replication or strict adaptation.

## Controlled source treatment

- `KEEP`: Retain the original image if authorized; document that reuse and its rights status.
- `REPLACE`: Replace with a new or supplied image in the **same medium** unless requested otherwise; preserve crop and lighting logic.
- `REMOVE`: Remove all sample UI, metrics, creator credits, unrelated badges and unsupported claims, **including text embedded in source photos**.
- `FREE`: Reimagine material only in an inspiration or original-creation brief.

Check extraction edges at actual size. Rough cutouts, bright halos, remnants of source pixels, inconsistent sharpness and warped proportions are visual failures, even if the output file dimensions are correct.

## Provenance and rights

User-uploaded reference imagery is valid evidence for an internal benchmark, but is not automatically cleared for public commercial reuse. If a photograph is reused, describe that honestly. Do not claim to have produced a new photograph. Record original file identity and hash if using it in tests.

**Review evidence:** source/target crop comparison, bounding-box preservation, exact material classification, image rights status, all visible unsupported embedded copy, and cutout-quality observations. An automated image-hash match can establish reused pixels but not artistic fidelity.
