# Art-direction atlas — broad expressive range without style autopilot

This atlas is a decision aid, not a list of presets to apply in order. Start from the brief, not from the name of a style. Do not treat social media, branding or “modern” as permission to insert navigation bars, cards or fake app screens.

For each direction, the **artistic mechanism** matters more than surface motifs:

| Direction | Core visual logic | Typography | Image/material | Risk to reject |
|---|---|---|---|---|
| Restrained modernism | exact structure and negative space | disciplined sans, purposeful weight change | few strong shapes/real subjects | empty corporate sameness |
| Neo-Swiss | asymmetric but controlled grid, scalebreaks | grotesk and monumental display | precise crop and flat color | arbitrary micro-labels |
| Luxury editorial | sophisticated pacing and quiet confidence | expressive serif or custom letterform with calm support | close-ups, human tactility, premium light | cheap gold gradients, faked luxury seals |
| Bold typographic | type as protagonist and meaning | deliberate scale, counterform, unusual breaks | minimal supporting image | oversized type with no concept |
| Minimal conceptual surrealism | one improbable but coherent visual metaphor | quiet direct headline | credible composite, single physical paradox | random floating objects |
| Cinematic advertising | dramatic scene with believable light and story | secondary, atmosphere-aware | photography, depth, authentic materials | generic blue/orange glow and dust |
| Maximalist editorial | controlled density with intentional hierarchy | layered expressive type | curated collage, references, imagery | saturation everywhere, unreadable clutter |
| Tactile modernism | traces of physical process and material | warm functional type | paper, print grain, woven fibers, ink | fake grunge overlay |
| Constructivist / poster-driven | geometric tension and directional hierarchy | assertive letterforms | flat shapes, diagonals, limited colors | propaganda imitation without context |
| Organic visual systems | living irregularity organized by repeatable rules | humanist, flexible type | shape families from nature/data | generic blob wallpaper |
| Playful commercial illustration | characterful shapes with sharp message | friendly but controlled | 2D, cutout, humorous scale | random sticker clutter |
| Hyperreal product focus | material truth, precision, believable scale | restrained product copy | studio light, authentic surfaces | CGI plastic texture, fantasy hardware |
| Archival / vernacular | authentic historical logic and cultural detail | documented period-appropriate lettering | source-authentic ephemera | false provenance, stereotype |
| Experimental mixed-media | disruptive but meaningful combinations | disciplined across texture shifts | collage, physical props, illustration | arbitrary clipped hands or stock packs |
| Diagrammatic clarity | explanatory order and comprehension | numeric and label hierarchy | clean vector pictograms/data | unverified charts or fake metrics |
| Expressive hand-crafted | gesture, variation, human marks | lettering or carefully chosen type | ink, paint, paper, woodcut | illegible decorative excess |

## Direction-building method

Choose **visual decisions**, not a style package:
1. Dominant communication mechanism: story, gesture, product, type, contrast, explanation.
2. Space: tightly framed / wide void / radical crop / layered depth / strict grid / freely composed.
3. Image medium: authentic photo / vector / collage / print / 3D / mixed, consistent with explicit constraints.
4. Letter voice: sober / expressive / documentary / elegant / playful / utilitarian.
5. Palette behavior: monochromatic restraint / split complement / neutral with one accent / material-native / full-spectrum controlled.
6. Surface character: pure flat / tactile / natural light / intentionally artificial.

**Aesthetic diversity exercise:** If three proposals can be described as “same layout, different background”, reject and reconceive. Different ideas should differ in content, meaning, and viewing experience; a brand campaign can remain consistent without using identical posters.

## Style separation in project memory

A style or motif becomes reusable only when the client's brand system or user brief approves it. Never carry a specific project's orange contours, green palette, editorial cards or brand-specific wordmark into another project. Contrast reference studies are examples of **mechanisms**, not source code for reassembly.

## Modern does not mean interface

Only use tabs, floating feature cards, buttons, status badges and navigation headers when the requested deliverable is a UI, UX screen, presentation of a digital product, or when the brief explicitly calls for them. Modern advertising can be cinematic, typographic, tactile, minimal, poetic, narrative or abstract and require **zero UI elements**.
