# Color: relationships, emotion, function and accessibility

**Conceptual influence:** Josef Albers; complementary production/accessibility guidance is independently derived.

## Roles before swatches
Define a palette by *function*: `canvas`, `primary text`, `support text`, `brand`, `attention accent`, `surface/overlay`. Select 1–2 lead hues, appropriate neutrals and at most a few intentional accents; a maximalist design can use more if hierarchy remains evident.

## Visual decision rules
- Color appearance is relational. Evaluate every pair against its actual surrounding colors and at real scale; a hex code by itself is not a design.
- Separate hierarchy by lightness as well as hue. Test grayscale to detect a design whose emphasis disappears without color.
- Use temperature, saturation and value to shape mood. For example: dusty warm tones and deep ink for human warmth; clean neutrals and precise bright accents for high-clarity information.
- Keep functional text readable in practice. For web-style accessible normal text, target >= 4.5:1 contrast; large text >= 3:1 under WCAG AA text criteria. Print and artistic compositions still need contextual readability evaluation.
- Test artwork against both intended screen and printing conditions. RGB and CMYK reproduction differ; proof saturated colors and deep shadows.
- Do not let a gradient do the job that hierarchy, composition and good typography should do.

## Contemporary palette patterns (starting points; test contrast)
- **Ink & bone:** #121212 / #F1EDE4 / #B59D77 / #6E665E — refined editorial.
- **Acid utility:** #101113 / #F6F5EF / #D7FF3F / #656B78 — art, music, youth tech.
- **Terracotta & moss:** #F3E7D8 / #A34833 / #505C3A / #2C2925 — tactile, culture, hospitality.
- **Digital cobalt:** #0E173D / #E9ECF7 / #305BFF / #C5F1E8 — modern innovation.
- **Monochrome + shock:** #0B0B0B / #FFFFFF / #FF5333 — direct communication, high-energy poster.
- **Deep plum & champagne:** #271727 / #F3E8D4 / #A88763 / #F4BFCB — fashion and beauty.

These are illustrative candidates. Verify contrast before treating any text/background pair as compliant.

## Reject and repair
- **Reject** visually muddy accent color against a similarly valued background. **Repair:** adjust lightness or reposition.
- **Reject** four equally saturated hues vying for the headline. **Repair:** give one color the attention role.
- **Reject** a rainbow gradient chosen as a universal “premium” shortcut. **Repair:** justify color by concept and brand.
- **Reject** using color alone to indicate important distinctions. **Repair:** combine with labels, shapes or positioning.

## “What the book would reject” heuristic
A palette is not a row of isolated color chips. Color is a set of **relationships** that must work in context.
